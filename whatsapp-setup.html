❓ Frequently Asked

QR code tidak muncul?

Solusi:

  • Tunggu 5-10 detik untuk server load
  • Klik tombol "Refresh QR"
  • Restart server jika masih tidak muncul
Status "Disconnected" setelah scan?

Solusi:

  • Refresh QR code (berlaku 30 detik)
  • Scan ulang dengan cepat
  • Pastikan koneksi internet ponsel stabil
Reset session?

Petunjuk:

  • SSH: rm -rf data/wa-auth/
  • Restart server
  • Scan QR code baru

Penyebab: Server belum selesai initialize WhatsApp service

Solusi:

  • Tunggu 5-10 detik untuk server load

Status masih "Disconnected" setelah scan?

Penyebab: QR code sudah expired atau scan gagal

Solusi:

  • Klik "Refresh QR Code" untuk generate QR baru
  • Scan ulang dengan cepat (QR berlaku 30 detik)
  • Pastikan koneksi internet ponsel stabil
  • Cek log server untuk error message
Test message tidak terkirim?

Penyebab: Koneksi belum stabil atau circuit breaker aktif

Solusi:

  • Pastikan status connection: "Connected ✓"
  • Cek circuit breaker status (jika "Open", tunggu 5 menit)
  • Verifikasi format nomor telepon (62 + nomor)
  • Tunggu 10-20 detik sebelum retry (anti-ban protection)
