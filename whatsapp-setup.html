Troubleshooting

Solutions untuk masalah umum

QR Code tidak muncul?

Penyebab: Server belum selesai initialize WhatsApp Baileys service

Solusi:

  • Tunggu 5-10 detik untuk server load
  • Klik tombol "Refresh QR"
  • Cek terminal server: apakah ada log "[WhatsApp] QR Code generated"?
  • Restart server jika masih tidak muncul
Status masih "Disconnected" setelah scan QR?

Penyebab: QR code sudah expired atau scan tidak berhasil

Solusi:

  • Klik "Refresh QR" untuk generate QR code baru
  • Scan dengan cepat sebelum QR code expired (biasanya 20-30 detik)
  • Pastikan koneksi internet ponsel stabil saat scan
  • Cek log server untuk error message
Test message tidak terkirim?

Penyebab: Koneksi belum stabil atau circuit breaker aktif

Solusi:

  • Pastikan status connection: "Connected ✓"
  • Cek circuit breaker status (jika "⚠️ Open", tunggu 5 menit)
  • Verifikasi format nomor telepon (62 + nomor, contoh: 628123456789)
  • Tunggu 10-20 detik sebelum retry (anti-ban protection aktif)
Ingin reset session WhatsApp?

Petunjuk: Hapus session dan setup ulang

  • SSH ke server: rm -rf data/wa-auth/
  • Restart server: npm start
  • Klik "Refresh QR" untuk generate QR code baru
  • Scan QR code dengan ponsel Anda
