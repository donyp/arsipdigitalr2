Cara kerja sistem token:

  • Admin Zona: tiap user punya token sendiri, dikirim ke email masing-masing.
  • Moderator / Super Admin: satu token bersama, dikirim ke 1 email.
  • Token berlaku hanya hari itu (expire saat jam auto-logout berikutnya).
  • Setelah user sekali verifikasi token, login berikutnya cukup user + password (tanpa token) sampai reset harian.
  • Generate & kirim otomatis berjalan 1 jam setelah jam auto-logout.
