  TESTING CEPAT
================================================================================

Sebelum integrate ke production, test dengan:

1. Create invoice via API:
   curl -X POST http://localhost:3000/api/invoices \
     -H "Authorization: Bearer TOKEN" \
     -H "Content-Type: application/json" \
     -d '{
       "nomor_invoice": "TEST-001",
       "jumlah": 1000000,
       "toko_id": 1,
       "kategori": "PPN"
     }'

2. Buka dashboard:
   http://localhost:3000/audit-logs.html

3. Filter untuk melihat log yang baru dibuat:
   - Resource Type: invoice
   - Operation: CREATE

4. Klik "View" untuk melihat detail lengkap

================================================================================
  QUICK COMMAND REFERENCE
================================================================================

View logs via API:
  curl -X GET "http://localhost:3000/api/audit-logs?limit=10" \
    -H "Authorization: Bearer TOKEN"

Filter by resource type:
  curl -X GET "http://localhost:3000/api/audit-logs?resourceType=invoice" \
    -H "Authorization: Bearer TOKEN"

Get suspicious only:
  curl -X GET "http://localhost:3000/api/audit-logs/suspicious" \
    -H "Authorization: Bearer TOKEN"

Get stats:
  curl -X GET "http://localhost:3000/api/audit-logs/stats" \
    -H "Authorization: Bearer TOKEN"

Export CSV:
  curl -X GET "http://localhost:3000/api/audit-logs/export/csv" \
    -H "Authorization: Bearer TOKEN" > audit-logs.csv
